==========================================================
  PROJECT SELF-MANAGEMENT — HOW IT'S HOSTED (Convex backend + GitHub Pages)
==========================================================

The app has two halves:

  FRONTEND  index.html  ......  hosted free on GitHub Pages
                                https://eloren18.github.io/project-self-management/
  BACKEND   convex/ folder ...  hosted free on Convex (database + sign-in)
                                dashboard: https://dashboard.convex.dev
                                project "claude-self-management", team "kerem-ekdal"
                                PRODUCTION: https://cheerful-rat-350.convex.cloud   (what the live site uses)
                                DEV:        https://hearty-jay-608.convex.cloud     (testing only)

Your workspace (work + personal) is stored in Convex, tied to your email,
and syncs live across every device you sign in on. Sign-in = your email +
a 6-digit code emailed to you. Codes are sent through Resend
(https://resend.com) — the free plan delivers only to the email the Resend
account was created with (keremladkeholland@gmail.com), which is also the
app's admin email. Only that email can ever sign in (enforced on the server).

Devices: the first device you sign in on is trusted automatically; every
later device must be approved from a trusted one (Security → Devices). The
server only answers data requests from trusted devices.

Backups: Security → Backups → "⤓ Download full backup" downloads everything
as one JSON file; "⤒ Restore from backup file…" restores one. Cloud snapshots
are taken automatically (every 4h of activity, newest 30 kept) and appear
under Restore points together with this device's local safety copies.


----------------------------------------------------------
UPDATING THE APP
----------------------------------------------------------
- Frontend change (index.html): run Deploy.bat (commits + pushes; GitHub
  Actions republishes the site within a minute).
- Backend change (anything in convex/): in this folder run
      npx convex deploy -y
  (or double-click Deploy-Backend.bat). The frontend and backend are
  independent — deploy whichever you changed. The browser client version
  pinned in index.html (convex@1.45.0) should match package.json.
- Local testing against the DEV deployment: `npx convex dev --once` pushes
  to dev (hearty-jay-608); the page can be pointed at another backend via
  localStorage key "psmConvexUrl" (never needed in normal use).
- Safe sanity check of what's stored (counts/sizes only, never contents):
      npx convex run admin:stats --prod


----------------------------------------------------------
ONE-TIME SETUP (already done — for reference / a new machine)
----------------------------------------------------------
1. `npm install` in this folder (installs the convex CLI).
2. `npx convex dev --once` (logs in, links the project, writes .env.local —
   git-ignored).
3. Resend API key (shared with the Budget app's Resend account):
      npx convex env set RESEND_API_KEY re_xxx
      npx convex env set --prod RESEND_API_KEY re_xxx
4. `npx convex deploy -y` to push the backend to production.
5. GitHub Pages: repo → Settings → Pages → Source "GitHub Actions"
   (.github/workflows/deploy.yml publishes index.html on every push).


----------------------------------------------------------
MIGRATION FROM INSTANTDB (Aug 2026)
----------------------------------------------------------
The app ran on InstantDB + Google sign-in until 2026-08-22, when everything
(workspace, 30 cloud snapshots, security log, devices) was exported with an
admin token and imported into Convex 1:1 (verified by counts and bytes).
The one-off migration tools and the old InstantDB schema/perms were removed
after the cutover — git history has them if ever needed. The InstantDB app
itself is untouched as a fallback until ~2026-09-05, then it can be deleted.


----------------------------------------------------------
SECURITY NOTES
----------------------------------------------------------
- Only the admin email can request a sign-in code (server-enforced). Codes
  are hashed, expire after 10 minutes, allow 5 wrong tries, 30s between
  sends, 15 sends/day. Sessions last ~6 months per device (max 10).
- Data functions (workspace, snapshots, security log) require BOTH a valid
  session AND a trusted device. Approving/revoking devices requires a
  trusted caller. "Sign out all other devices" also drops their sessions.
- The admin email is set in TWO places: index.html (ADMIN_EMAIL) and
  convex/lib.ts (ADMIN_EMAIL). Change both if it ever changes, then deploy
  both halves. The test suite (tests/e2e-sync.mjs, S16) checks they match.


----------------------------------------------------------
BANDWIDTH & HOUSEKEEPING (Sep 2026)
----------------------------------------------------------
- Devices subscribe to a tiny version record (workspaceMeta) and fetch the
  workspace blob only when another device changed it; keystrokes are batched
  into one push per pause (flushed at once when the tab is hidden or closed).
  Expect single-digit MB of database bandwidth per day; if the dashboard shows
  hundreds of MB again, something is pushing per keystroke.
- Snapshots: metadata rows (snapshots) + blobs (snapshotBlobs). Automatic
  snapshots are gated server-side to one per 4h across all devices.
- Workspace size limit: 250 KB (UTF-8). Today ~85 KB.
- Daily cron (convex/crons.ts → maintenance:cleanup, 03:15 UTC) removes stale
  sign-in codes, expired sessions and security-log rows older than 90 days.
  Run by hand:   npx convex run maintenance:cleanup --prod
- Session tokens are stored hashed (SHA-256). Old raw-token sessions upgrade
  themselves the first time that device opens the app after the update.
- Sign-in codes: 5 wrong tries kill a code (fixed Sep 2026 — the counter used
  to be rolled back), used codes stay on record so the 30s / 15-per-day limits
  keep counting.

----------------------------------------------------------
TROUBLESHOOTING
----------------------------------------------------------
- Code email not arriving: check spam; make sure you typed the admin
  email; Resend free plan only delivers to that address.
- "A code was just sent": wait 30 seconds and try again.
- Header pill red "Not synced": the browser can't reach Convex (offline, or
  a network blocking *.convex.cloud). Your edits are kept on the device
  and pushed when the connection is back.
- "Approval needed" on a new device: open the app on a trusted device →
  Security → Approve.
- See what's stored: dashboard.convex.dev → claude-self-management → Data.
