PART 1 — Create a Google Client ID
----------------------------------------------------------
1. Go to  https://console.cloud.google.com/  and sign in with
   keremladkeholland@gmail.com.

2. Create a project (top bar → project dropdown → "New Project").
   Name it e.g. "Self-Management". Select it.

3. Left menu → "APIs & Services" → "OAuth consent screen".
   - User type: "External" → Create.
   - App name: "Project Self-Management". User support email: your email.
   - Developer contact: your email. Save and continue through the steps.
   - On "Test users" (or "Audience"): add  keremladkeholland@gmail.com.
     (You can leave it in "Testing" mode — that's fine for personal use and
      actually TIGHTENS access to listed test users.)

4. Left menu → "APIs & Services" → "Credentials" →
   "Create Credentials" → "OAuth client ID".
   - Application type: "Web application".
   - Name: "psm-web".
   - Under "Authorized JavaScript origins", click ADD URI and add your
     site's ORIGIN (no path), for example:
         https://YOURNAME.github.io
     (If you'll also test locally, add  http://localhost:8091  too.)
   - You can leave "Authorized redirect URIs" empty (we use the button flow).
   - Click Create.

5. Copy the "Client ID" it shows you (ends in
   .apps.googleusercontent.com).

6. Open  index.html  in Notepad. Near the top of the <script>, find:
         const GOOGLE_CLIENT_ID = "";
   Paste your Client ID between the quotes. Save.


----------------------------------------------------------
PART 2 — InstantDB: connect Google
----------------------------------------------------------
1. Go to  https://instantdb.com  and sign in.

2. Open your app (App ID 62048635-507a-4feb-9d3b-69941179a9fc).

3. Left menu → "Auth" → "Google".
   - Click "Add Google client" (or "Set up").
   - Client name:  google-web
     ^^^ IMPORTANT: it must be EXACTLY  google-web  — that's what index.html
         sends (the GOOGLE_CLIENT_NAME line). If you use a different name,
         change that line in index.html to match.
   - Google Client ID: paste the SAME Client ID from Part 1 step 5.
   - Google Client Secret: in Google Cloud → Credentials → your client, copy
     the "Client secret" and paste it here (Instant needs it to verify tokens).
   - Save.

4. IMPORTANT — still in InstantDB "Auth" tab, find "Redirect Origins" (a.k.a.
   approved origins). Click Add and add your site's ORIGIN (no path):
         https://YOURNAME.github.io
   This is REQUIRED even for the Google button. It is SEPARATE from the Google
   Cloud origin in Part 1 — you need BOTH lists to contain the same origin.
   Without it, sign-in reaches Google, you pick your account, then it fails with
   "Validation failed for origin: Unauthorized origin."

      "delete": "false"

      "create": "auth.id != null && 'keremladkeholland@gmail.com' in auth.ref('$user.email')",
      "update": "auth.id != null && 'keremladkeholland@gmail.com' in auth.ref('$user.email') && auth.id in data.ref('owner.id')",
      "delete": "auth.id != null && 'keremladkeholland@gmail.com' in auth.ref('$user.email') && auth.id in data.ref('owner.id')"

----------------------------------------------------------
ADDING A NEW DEVICE LATER (phone, laptop)
----------------------------------------------------------
- Open the SAME address on the new device → Sign in with Google.
- It will say "Approval needed". On a device you ALREADY trust, open the app
  → shield icon (top right) → find the new device under "Awaiting approval"
  → Approve. The new device unlocks automatically (no refresh).
- To kick a device out: shield icon → Revoke. It's signed out immediately and
  must be re-approved.


----------------------------------------------------------
TROUBLESHOOTING
----------------------------------------------------------
- "Finish setup" screen won't go away: GOOGLE_CLIENT_ID is still empty in
  index.html, or you uploaded the file before pasting it. Re-check Part 1 step 6.
- Google button does nothing / "origin not allowed": the site address doesn't
  match "Authorized JavaScript origins" in Google Cloud (Part 1 step 4). They
  must be identical, https, no trailing path.
- "Validation failed for origin: Unauthorized origin" (AFTER you pick your Google
  account): your site origin is missing from InstantDB's "Redirect Origins" list.
  Add it in Instant → Auth → Redirect Origins (Part 2 step 4). This is a DIFFERENT
  list from the Google Cloud one in Part 1 — the origin must be in BOTH.
- "Access denied" after signing in: you used a different Google account. Only
  keremladkeholland@gmail.com is allowed. Sign out and use the right account.
- Signed in but stuck on "Approval needed": approve it from an already-trusted
  device (shield icon). The very first device ever is auto-trusted.
- Data not syncing: confirm Part 3 permissions were saved, and that Google is
  connected in Instant with the client name EXACTLY  google-web  (Part 2).
